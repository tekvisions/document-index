Recover text

Test native-text and scanned inputs separately. Check languages, rotation, page quality and whether the output preserves the text you actually need.

Recover usable structure

Specify reading order, headings, cells, merged tables and output schema. Compare extracted fields with a manually checked document sample.

Interpret document content

Define questions and required evidence locations. Verify both answer correctness and whether the output identifies the supporting page or region.

  • Record file formats, document languages, runtime/model version and hardware.
  • Include difficult and failed documents; report extraction errors by field or page.
  • Verify license, local/cloud processing and data-handling requirements in primary documentation.

How is the default order determined?

Momentum blends log-scaled GitHub stars (55%), push recency decaying over 180 days (32%), and a young-repository bonus for repositories under 120 days old with at least 20 stars (13%), rounded and clamped to 1–100. Configured searches select the catalog; coverage is not exhaustive. Stars and repository activity are proxies, not measured adoption, reviews, security or product-quality benchmarks.
